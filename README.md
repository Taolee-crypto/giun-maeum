# 🌿 기운과 마음 (Giun Maeum)

**사주 × MBTI × 타로** 기반 개인 상담 앱

## ✨ 기능

### 사주 명식 + 일간 상세 해석
- 년·월·일·시주 (천간지지)
- **일간(日干) 10종** 상세 해석 (갑~계)
  - 핵심 성향, 강점, 성장 포인트
  - 학생·직업 방향 힌트
- 오행 균형 시각화

### MBTI 12문항 + 상세 상담
- 진로·직업 / 학생 진로 / 관계 / 의사결정 / 자기돌봄
- 과목·전공·직업 추천

### 타로 (메이저 아르카나 22장)
- 3장 스프레드: 현재의 에너지 · 주의할 점 · 앞으로의 흐름
- 다시 뽑기 지원

## 사용법

```bash
git clone https://github.com/Taolee-crypto/giun-maeum.git
cd giun-maeum
# index.html + app.js 를 브라우저로 열기
```

**완전한 단일 파일**이 필요하면 대화에서 제공한 `giun-maeum-complete.html` 을 사용하세요.

## 주의
- 절기·시주는 근사 계산입니다.
- 타로는 미래를 단정하지 않으며, 자기 성찰용 거울입니다.
- 전문 상담을 대체하지 않습니다.
