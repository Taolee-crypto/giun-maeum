# 🌿 기운과 마음 (Giun Maeum)

**사주 × MBTI** 기반 개인 상담 앱 MVP

생년월일과 12문항 성향 질문으로 **오행(木火土金水) + 인지기능** 조합 프로필을 생성하고, 맞춤형 조언·유사 인물·강점/성장 포인트를 제공합니다.

> 모든 연산은 **브라우저(클라이언트)에서만** 처리됩니다. 서버에 어떠한 개인 정보도 저장되지 않습니다.

## ✨ 주요 기능 (MVP)

- 생년월일 입력 (양력/음력 선택, 시간 선택 가능)
- 12문항 MBTI 성향 질문
- 오행 + 주요 인지기능 조합 프로필 생성
- 나와 닮은 기운의 역사적 인물 + 팁
- 강점 & 성장 포인트
- 오늘의 조언 (Do / Avoid)
- 4가지 상담 카테고리: 진로·직업 / 관계 / 의사결정 / 자기돌봄

## 🚀 바로 사용하기

GitHub Pages가 활성화되어 있다면 아래 주소로 접속할 수 있습니다:

```bash

cd giun-maeum
# 그냥 index.html을 브라우저로 열기
```
